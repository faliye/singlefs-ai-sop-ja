# コミュニケーション規律

**対象**：agent から利用者への会話、および agent 同士の会話。

## 社交辞令を書かない

返信とメッセージに書かないもの：挨拶、礼、謝罪、質問を褒めること、「承知しました」「もちろん」「喜んで」、末尾の「他にご用はありますか」。

終了時フック `scripts/claude-hooks/courtesy-phrase-check.sh` がこの条を判定する：そのターンの最後の返信に語彙リストの言い回しがあれば、終了を止め、消して書き直させる。同じ返信を止めるのは一度だけ。
認識する言い回しはそのフックの `COURTESY_PHRASES` のとおりで、バッククォート、「」、引用符、コードブロックの中は判定しない。語彙リストは中国語だけで、英語と日本語の返信は判定しない。
プロジェクトは `.claude/settings.json` の `Stop` と `SubagentStop` にそれぞれ一度ずつ登録する。書き方はそのフックのファイル先頭にある。

## よそのやり方を伝えるときは、出所か原文を付ける

サブエージェントに渡すプロンプト、別のセッションに送るメッセージで、「X と同じ口径」「X のあの一份のとおり」「`X` と同じ」と言う一文には、同じ一文の中に次のどれか一つを付ける：

- `パス:行番号`（またはパスか「同じファイル」に「第 N 行」を添える）；
- 原文の引用：「」の中に 6 文字以上、またはコロンで終わり次の行が `>` で始まる引用行；
- パスとバッククォートで囲んだ関数名、または「」で囲んだ見出し。

原文が何か自信がなければ、渡す前に自分で読む。自分の理解だけを書いたもの（「同じ口径：修飾名を取る」）は出所にならない。

フック `scripts/claude-hooks/borrowed-convention-guard.sh`（判定は `scripts/borrowed-convention.py`）がこの条を判定する：サブエージェントを出す前（Agent、Task）と SendMessage の前に判定し、借用の一文に同じ一文の中で出所も原文も無ければ拒否する。
認識する借用の言い回しは `scripts/borrowed-convention.py` の `BORROW_PHRASES` のとおりで、そこに無い言い回しは判定しない。出所の指す先が正しいか、原文を正しく写したかは判定しない。
プロジェクトは `.claude/settings.json` に登録する。書き方はそのフックのファイル先頭にある。

## 範囲と例外

第三者が読む成果物（メール、告知、外部向け文書）は読み手に合わせて書く。範囲の外である。
